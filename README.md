# Meta AI demo

A responsive, single-page chat interface inspired by Meta AI. Open `index.html` in a browser to try it—no build tools or dependencies required.

## What’s included

- Responsive chat layout with recent-chat navigation and prompt suggestions
- Working composer with Enter-to-send and Shift+Enter for a new line
- Local sample responses so the interface works without an API

## Connecting a real AI model

The responses in this demo are deliberately local examples, not a live AI model. For production, send prompts to your own server-side endpoint and call your chosen AI provider there. Keep provider credentials on the server; never put API keys in browser code.
